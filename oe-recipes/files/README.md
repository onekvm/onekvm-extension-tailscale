# Go dependency license fingerprints

`license-hashes.csv` supplies exact notice fingerprints to OE's standard
license finder when regenerating the module/license includes. Existing
classifications are retained from the pinned meta-networking Tailscale
metadata and the reviewed NetBird dependency notices.

The new `github.com/bradfitz/monogok` notice at
`v0.0.0-20260630033929-b1eef977b41f` has MD5
`32c87c5071c476dfcb4de7a5890010f3`. Its complete notice grants redistribution
subject to source-notice, binary-notice and non-endorsement conditions, with
the standard warranty disclaimer: BSD-3-Clause.

Source: https://github.com/bradfitz/monogok/blob/b1eef977b41f/LICENSE
